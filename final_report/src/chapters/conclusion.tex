\chapter{CONCLUSION}

This project demonstrated the feasibility of developing a locally deployable AI-based code generation system using parameter-efficient fine-tuning techniques. By leveraging the LLaMA-2 7B model and optimizing it through QLoRA, the system successfully achieved efficient training and inference under limited computational resources.

A structured pipeline was implemented, encompassing dataset preparation, instruction formatting, low-rank adaptation, and hyperparameter optimization. The use of QLoRA enabled significant reduction in memory usage while maintaining strong generative performance, making it suitable for consumer-grade hardware environments.

Experimental results indicate that the fine-tuned model achieved notable improvements across multiple evaluation metrics, including BLEU, CodeBLEU, and functional correctness measures such as pass@k. These results highlight improvements in both syntactic quality and semantic correctness of the generated Python code.

Furthermore, the system was successfully deployed using Ollama, enabling efficient local inference and demonstrating the practicality of running large language models without reliance on cloud-based infrastructure. This contributes to improved accessibility, privacy, and cost efficiency.

\section{Key Achievements}

The major contributions of this project are summarized as follows:
\begin{itemize}
    \item Successful implementation of QLoRA-based fine-tuning for efficient adaptation of a large language model.
    \item Development of a complete training pipeline with structured data preprocessing and hyperparameter optimization.
    \item Demonstration of improved code generation performance using both automated and functional evaluation metrics.
    \item Deployment of the fine-tuned model for local inference using Ollama on consumer-grade hardware.
\end{itemize}

\section{Final Remarks}

This work highlights the growing importance of parameter-efficient techniques in making large language models more accessible and practical. The proposed approach demonstrates that high-quality code generation can be achieved without requiring large-scale computational infrastructure.

With continued advancements in dataset quality, evaluation strategies, and model scaling, such systems have strong potential to support real-world software development, competitive programming, and intelligent coding assistance. The project provides a solid foundation for future research in efficient and deployable AI-driven code generation systems.
