\bigskip

Large Language Models (LLMs) have demonstrated strong capabilities in natural language understanding and code generation. However, their deployment in resource-constrained environments remains challenging due to high computational and memory demands. This study proposes an efficient approach for Python code generation by fine-tuning a LLaMA-2 7B chat model using the Quantized Low-Rank Adaptation (QLoRA) technique. A high-quality training dataset is constructed and refined through a teacher-model-based filtering approach to improve data reliability, while structured prompt formatting is incorporated to enhance logical consistency in generated outputs. The fine-tuned model is evaluated on the HumanEval benchmark using pass@k metrics, demonstrating significant improvements over baseline performance in functional correctness. Furthermore, the model is deployed locally using Ollama, enabling efficient and cost-effective inference without dependence on cloud infrastructure. The results highlight the effectiveness of parameter-efficient fine-tuning combined with optimized data curation in developing practical and high-performance code generation systems suitable for real-world applications such as intelligent coding assistants and educational tools.

\noindent\textit{\textbf{Keywords}}---LLMs, LLaMA-2, Code Generation, PEFT, QLoRA, LoRA, Hugging Face, Ollama, Local Inference, Prompt Engineering.
