\chapter{MATHEMATICAL DERIVATIONS}
This chapter provides a detailed mathematical framework for the fine-tuning process, the optimization algorithms, and the low-rank adaptation (LoRA) used in our project for code generation with Llama-2-7B.

\section{Low-Rank Adaptation (LoRA) Derivation}
LoRA aims to reduce the number of trainable parameters during fine-tuning by constraining the weight updates to a low-rank decomposition. For a pre-trained weight matrix $W_0 \in \mathbb{R}^{d \times k}$, the LoRA update is defined as:
\[
\Delta W = BA
\]
where 
$B \in \mathbb{R}^{d \times r}$, $A \in \mathbb{R}^{r \times k}$, and $r \ll \min(d,k)$ is the rank of the adaptation.  

The forward pass for an input vector $x \in \mathbb{R}^{k}$ becomes:
\[
h = W_0 x + \Delta W x = W_0 x + B A x
\]

\subsection{Gradient Computation}
During backpropagation, only $A$ and $B$ are trainable. Let $\mathcal{L}$ denote the loss function. The gradients of the loss with respect to the LoRA parameters are computed using the chain rule:
\[
\frac{\partial \mathcal{L}}{\partial A} = B^\top \frac{\partial \mathcal{L}}{\partial h} \, x^\top
\]
\[
\frac{\partial \mathcal{L}}{\partial B} = \frac{\partial \mathcal{L}}{\partial h} \, (A x)^\top
\]

This formulation avoids computing gradients for the large pre-trained weight $W_0$, significantly reducing memory usage and computational cost.

\subsection{Rank-1 Decomposition Interpretation}
The LoRA update $\Delta W$ can also be expressed as a sum of rank-1 matrices:
\[
\Delta W = \sum_{i=1}^{r} B_{\cdot,i} A_{i,\cdot}
\]
where $B_{\cdot,i}$ is the $i$-th column of $B$ and $A_{i,\cdot}$ is the $i$-th row of $A$. This demonstrates that LoRA approximates the weight update using a combination of $r$ rank-1 matrices, capturing the most significant directions of change.

\subsection{Parameter Reduction}
The number of trainable parameters is reduced from $d \times k$ to $r \times (d + k)$:
\[
\text{Reduction Factor} = \frac{r \times (d+k)}{d \times k} \ll 1
\]
which shows the efficiency gained when $r \ll \min(d,k)$.

\section{Cross-Entropy Loss for Code Generation}
The model predicts the next token in a code sequence using Categorical Cross-Entropy. Let $y \in \{0,1\}^V$ be the one-hot encoded ground truth vector over vocabulary size $V$, and $\hat{y}$ be the predicted probability vector from the Softmax layer:
\[
\hat{y}_i = \frac{\exp(z_i)}{\sum_{j=1}^{V} \exp(z_j)}
\]

The Cross-Entropy loss for a single token is:
\[
\mathcal{L}_\text{CE} = - \sum_{i=1}^{V} y_i \log(\hat{y}_i)
\]

\subsection{Sequence-Level Loss}
For code sequences of length $T$, the total loss becomes:
\[
\mathcal{L}_\text{seq} = - \sum_{t=1}^{T} \sum_{i=1}^{V} y_{t,i} \log(\hat{y}_{t,i}) 
= - \sum_{t=1}^{T} \log P(y_t \mid y_1, \dots, y_{t-1}; \theta)
\]
where $\theta$ denotes the trainable parameters (here, LoRA parameters $A$ and $B$).

\subsection{Gradient Simplification for Softmax + Cross-Entropy}
A well-known simplification of the gradient of the loss with respect to the logits $z_i$ is:
\[
\frac{\partial \mathcal{L}_\text{CE}}{\partial z_i} = \hat{y}_i - y_i
\]
This avoids computing the full Jacobian of the Softmax, making backpropagation efficient.


\section{Regularization and Weight Decay}
If weight decay is applied to LoRA parameters, the total loss becomes:
\[
\mathcal{L}_\text{total} = \mathcal{L}_\text{seq} + \frac{\lambda}{2} \| \theta \|^2
\]
where $\lambda$ is the weight decay coefficient.

The gradient with respect to $A$ and $B$ is adjusted accordingly:
\[
\frac{\partial \mathcal{L}_\text{total}}{\partial A} = \frac{\partial \mathcal{L}_\text{seq}}{\partial A} + \lambda A, \quad
\frac{\partial \mathcal{L}_\text{total}}{\partial B} = \frac{\partial \mathcal{L}_\text{seq}}{\partial B} + \lambda B
\]

def tokenize_fn(batch):

    input_ids_list = []
    labels_list = []
    attention_mask_list = []

    for prompt, code in zip(batch["prompt"], batch["code"]):

        prompt = str(prompt)
        code = str(code)

        # Full formatted instruction
        full_text = prompt + "\n" + code

        tokenized = tokenizer(
            full_text,
            truncation=True,
            padding="max_length",
            max_length=MAX_LENGTH
        )

        input_ids = tokenized["input_ids"]
        attention_mask = tokenized["attention_mask"]

        # Tokenize only prompt to mask it
        prompt_ids = tokenizer(
            prompt,
            truncation=True,
            max_length=MAX_LENGTH
        )["input_ids"]

        prompt_len = len(prompt_ids)

        labels = [-100] * len(input_ids)

        # Enable loss only on code tokens
        for i in range(prompt_len, len(input_ids)):
            if input_ids[i] != tokenizer.pad_token_id:
                labels[i] = input_ids[i]

        input_ids_list.append(input_ids)
        labels_list.append(labels)
        attention_mask_list.append(attention_mask)

    return {
        "input_ids": input_ids_list,
        "labels": labels_list,
        "attention_mask": attention_mask_list
    }

def preprocess_function_with_masking(examples, tokenizer, max_seq_length):
    input_ids_list = []
    attention_mask_list = []
    labels_list = []

    prompts = examples["prompt"]
    completions = examples["code"]

    for prompt, completion in zip(prompts, completions):
        if not prompt.endswith((' ', '\n', '\t')) and not 
        completion.startswith((' ', '\n', '\t')):
            full_text = prompt + ' ' + completion
        else:
            full_text = prompt + completion

        full_text += tokenizer.eos_token

        tokenized_full = tokenizer(full_text, max_length=max_seq_length, 
                        truncation=True, padding=False)
        tokenized_prompt = tokenizer(prompt, max_length=max_seq_length,
                         truncation=True, padding=False)
        prompt_length = len(tokenized_prompt["input_ids"])

        input_ids = tokenized_full["input_ids"]
        labels = [-100] * prompt_length + input_ids[prompt_length:]

        input_ids_list.append(input_ids)
        attention_mask_list.append(tokenized_full["attention_mask"])
        labels_list.append(labels)

    return {"input_ids": input_ids_list, "attention_mask": attention_mask_list, 
            "labels": labels_list}

# ============================================================================
# DATA COLLATOR
# ============================================================================
class DataCollatorForCompletionOnlyLM:
    def __init__(self, tokenizer, max_length=None):
        self.tokenizer = tokenizer
        self.max_length = max_length

    def __call__(self, features):
        max_len = max(len(f["input_ids"]) for f in features)
        if self.max_length:
            max_len = min(max_len, self.max_length)

        batch = {"input_ids": [], "attention_mask": [], "labels": []}

        for feature in features:
            input_ids = feature["input_ids"][:max_len]
            attention_mask = feature["attention_mask"][:max_len]
            labels = feature["labels"][:max_len]

            padding_length = max_len - len(input_ids)
            input_ids += [self.tokenizer.pad_token_id] * padding_length
            attention_mask += [0] * padding_length
            labels += [-100] * padding_length

            batch["input_ids"].append(input_ids)
            batch["attention_mask"].append(attention_mask)
            batch["labels"].append(labels)

        return {k: torch.tensor(v) for k, v in batch.items()}
